# Vortex One — Saveetha Engineering College

Official website draft for **Vortex One**, the Baja SAE student engineering team representing Saveetha Engineering College.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Update team information

Most season-specific information is kept in `data/`:

- `data/teamData.ts` — current team members
- `data/vehicleSpecs.ts` — vehicle specifications
- `data/sponsors.ts` — sponsors and partners
- `data/legacyTimeline.ts` — verified team history
- `data/engineeringData.ts` — engineering disciplines/process
- `data/competitionData.ts` — Baja SAE information and official SAE reference

Replace placeholders only with verified team information.

## Images

Add real team/vehicle/engineering photographs under `public/images/` and update the relevant data/components.

## Important

The website should use official SAE International information for SAE-related claims and should not imply that Vortex One is operated or endorsed by SAE unless that relationship is officially authorized.
